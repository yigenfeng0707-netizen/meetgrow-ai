# MeetGrow AI · 会展招商增长智能体

输入展会 / 峰会 / 产业园推介会信息，生成可落地的招商增长方案。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html`、`landing.html` | 产品首页与落地页 |
| `MeetGrow_AI_User_Manual.docx` | 用户手册 |
| `个人版-MeetGrow_AI_Host/` | 个人版全部材料：可运行的 `MeetGrow_AI.html`、产品介绍 PPT、使用手册（docx/pdf）、SLA 服务等级协议、用户协议与隐私政策、退款与售后政策、V1.1 迭代需求规划、全面体检报告 |
| `个人版-MeetGrow_AI_Host/Demo输出_*.md` | 三份真实场景输出样例：2026 企业 AI 落地增长峰会、企业数字化转型实战训练营、智能制造产业园招商推介会 |
| `个人版-MeetGrow_AI_Host/市场启动_T*.md` | 市场启动执行包：种子用户招募、内容营销、短视频发布、社群运营、代理商招募、客户案例沉淀 |

前端实现另见 [meetgrow-ai-frontend](https://github.com/yigenfeng0707-netizen/meetgrow-ai-frontend)。
